# Study Tracker

Трекер учёбы для школьника или студента: учебные задачи, предметы, таймер занятий и простая статистика. Данные хранятся в SQLite и остаются после перезапуска.

Интерфейс на React, сервер на Node.js и Express. Авторизации нет: приложение рассчитано на одного человека на этом компьютере.

## Что нужно заранее

- Node.js 22.13 или новее (SQLite входит в Node, отдельно ставить базу не нужно)
- npm

Проверка версии:

```powershell
node -v
```

## Установка и запуск

Откройте два терминала в папке проекта.

Терминал 1 — backend:

```powershell
cd backend
npm install
npm run dev
```

Сервер будет доступен по адресу http://localhost:3001

Терминал 2 — frontend:

```powershell
cd frontend
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173

`npm run dev` во frontend перенаправляет запросы `/api` на backend, поэтому отдельно настраивать адрес сервера не нужно. Оба терминала должны оставаться открытыми.

Обычный запуск backend без автоперезапуска: в папке `backend` выполните `npm start`.

## Как проверить

1. Откройте http://localhost:5173 — на панели четыре карточки: всего задач, выполнено, не выполнено, часы учёбы.
2. На странице «Предметы» добавьте предмет, например математику.
3. На странице «Задачи» создайте задачу, измените её, отметьте выполненной и удалите.
4. На странице «Таймер» выберите предмет, нажмите «Начать занятие», подождите пару секунд и нажмите «Остановить». Занятие появится в истории.
5. На странице «Статистика» появятся часы по предмету, столбец за сегодня и общий прогресс.
6. Остановите backend и запустите снова: предметы, задачи и занятия на месте. Файл базы: `backend/data/study.db`.

Чтобы начать с пустой базы, остановите backend и удалите `backend/data/study.db`.

## API

| Метод | Адрес | Назначение |
| --- | --- | --- |
| GET | `/api/health` | проверка, что сервер отвечает |
| GET, POST | `/api/subjects` | список предметов и создание |
| DELETE | `/api/subjects/:id` | удаление предмета без задач и занятий |
| GET, POST | `/api/tasks` | список задач и создание |
| PUT | `/api/tasks/:id` | изменение задачи |
| PATCH | `/api/tasks/:id` | смена статуса |
| DELETE | `/api/tasks/:id` | удаление задачи |
| GET, POST | `/api/sessions` | история занятий и сохранение |
| DELETE | `/api/sessions/:id` | удаление занятия из истории |
| GET | `/api/stats?offsetMinutes=300` | сводка, часы по предметам и неделя |

Ошибки приходят как `{ "error": "текст" }` с кодом 400, 404 или 409.
